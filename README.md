## Runefall

A classless arena-and-dungeon RPG where each player builds their own kit from ten abilities. I'm making it on my own in
Godot 4 and C# (.NET 10), on a server-authoritative 60 Hz simulation that doesn't depend on the engine. It's playable
online through Steam's relay network. The server enforces fog of war, and a matchmaker fills empty seats with bots.
There's a five-player dungeon modeled on Mythic+ with a stand-in boss, and the first real boss is next.

Runefall is versioned in [Diversion](https://www.diversion.dev), not GitHub, so its history doesn't show up here.
